# 深圳二次函数授课网页

用于腾讯会议线上教学，包含37道深圳中考真题、模拟题和期中题。

## 功能

- 单题授课模式、题目放大、题目目录及筛选。
- 键盘板书、快捷公式、原题圈画、荧光笔和撤销。
- 逐段展示解析、二次函数参数和平移演示、课堂计时。
- 板书和练习记录保存在当前浏览器。
- 2022年平移题附授课校订说明并保留原稿对照。

## 文件与运行

网页源代码位于 `dist/`。无需安装依赖或构建。

```sh
python -m http.server 8000 --directory dist
```

打开 http://localhost:8000 。由于题库通过 fetch 加载，请使用本地服务器，不要直接双击 HTML。
